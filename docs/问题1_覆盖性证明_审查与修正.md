## 0. 一句话结论

现有证明链是

```
±1° 小角 → 区域「是」中心对称平行四边形 → R_c = D/2 → 以直径为直径的圆能覆盖
```

其中**第二步在条带（线性化）模型下严格成立，在精确楔交模型下不成立**（只是 O(δ²) 的近似，
δ=1° 时相对偏差 ≤ 6×10⁻⁴）。所以：

1. 作为**工程结论**（两站 ±1° 交会）：「能覆盖」成立，可以写进论文，但必须写明前提是条带线性化，
   或者给出精确模型的偏差量级；
2. 作为**数学定理**：「以定位区域直径为直径的圆必能覆盖」是**错的**，等边三角形就是反例
   （R_c = D/√3 ≈ 0.577D > D/2），而等边三角形正是 **Jung 定理的取等情形**；
3. **用 Jung 定理去证明「能覆盖」是方向性错误**：平面 Jung 给出的是 R_c ≤ D/√3，比 D/2 更大，
   它只能支持「一般情形不能覆盖」，不能支持「能覆盖」；
4. 题目说「若干检测点」：**≥3 个测点时该结论明显不成立**（本模型内可给出显式反例，见 §2 定理 5）。

## 1. 逐条审查

### 1.1 引理 1「定位区域是中心对称平行四边形」——**不成立（精确模型）**

写成公式，一个测站给出的是**锥（楔形）**

```
W(S, φ, δ) = { P : |∠(P−S, φ)| ≤ δ }
```

它在 S 处的两条边界射线夹角为 2δ。精确的定位区域 A = W(S₁,φ̂₁,δ) ∩ W(S₂,φ̂₂,δ)
由 4 条直线围成，是一个**四边形**：同一测站的两条边界线夹角为 2δ ≠ 0，因此四边形的一对对边
（分别来自两个测站）只有在两个测站的边界线恰好平行时才平行，区域也才可能中心对称，除非

```
θ ≡ 0 (mod π)  或  4δ ≡ 0 (mod π)        (θ 为两测站指向源的示向度方向之间的夹角)
```

即只有「两站与源近似共线」的退化情形（或 δ=45° 这种极端参数）才成立；
对 θ ∈ (2δ, π−2δ) 的一般交会，四边形不是中心对称的。精确几何与「中心对称」的
偏差是 O(δ)（条带模型丢掉了锥的 `p·e_i·tanδ` 一阶项），由此引起的 D 偏差数值上是 O(δ²)。

复算（脚本 [1] 段，θ=90°、r₁=r₂=1000 m、零误差）：

| 量 | 数值 |
|---|---|
| 精确 D | 49.385 m |
| 条带解析式 D | 49.370 m |
| 区域中心对称？ | **否** |
| 对边平行（平行四边形）？ | **否** |
| 精确 R_c | 24.693 m = D/2 |

> 结论：把「条带」写成恒等是**把模型当成了定理**。正确写法是
> 「在 ±1° 的**线性化（条带）模型**下，A 是中心对称平行四边形」，
> 并给出它与精确楔交的偏差量级（见 §2 定理 3）。

### 1.2 引理 2「对角线公式」——**正确**

在条带模型 `A = {p : |p·n₁| ≤ w₁, |p·n₂| ≤ w₂}`、`w_i = r_i tanδ`、
`θ = ∠(n₁, n₂)`（= 交会角）下，解 4 个线性方程组得两条对角线长

```
D∓ = 2 tanδ · √( r₁² + r₂² ∓ 2 r₁ r₂ cosθ ) / sinθ ,      D = max(D₋, D₊)
```

以及两个等价形式（余弦定理/中线公式）：

```
D₋ = 4 tanδ · R外 ,   R外 = L/(2 sinθ) 为 △S₁GS₂ 外接圆半径
D₊ = 4 tanδ · |G − M| / sinθ ,   M 为基线中点
D  = 4 tanδ · max( L/(2 sinθ), |G − M|/sinθ )
```

我用独立实现复算过论文表格（脚本 [1] 段）：解析值与精确楔交 D 的相对偏差
在 θ=60°–150° 全部 ≤ 0.09%（例如 θ=60°：69.884 vs 69.820 m）。
**这一步没有问题**，但论文里 `D = max(D₋, D₊)` 的取法应说明「哪一支对应平行四边形哪条对角线」，
否则读者会怀疑取错（实测 θ=60° 时两式分别给出 40.3 m 与 69.8 m，取大者与精确值一致）。

### 1.3 引理 3「R_c = D/2」——**前提成立时才成立**

证明本身没问题：中心对称凸集的最小外接圆圆心必在对称中心（否则朝偏离方向平移圆心可同时减小
所有顶点的距离，与最小性矛盾），故半径 = 到最远顶点的距离 = D/2，且此时
**以直径对为直径的圆就是最小外接圆**。

但由 §1.1，精确区域的中心对称性不成立，所以 `R_c = D/2` 只是近似。随机扫描（脚本 [2] 段，
2 万个 (θ, r₁, r₂, e₁, e₂) 样本、δ=1°）：

| 项 | 结果 |
|---|---|
| R_c > D/2 的样本比例 | 1.25% |
| 最坏相对超出 (R_c−D/2)/(D/2) | **5.78×10⁻⁴**（≈ 0.058%） |
| 最坏样本 | θ=89.3°, r₁=736.7, r₂=1389.2, e=(+0.15°, −0.60°) |
| 该样本 D / R_c / 超出 | 54.598 m / 27.315 m / 0.0158 m |

标度实验（脚本 [2b] 段）显示最大相对超出 ∝ δ²：

| δ | max (R_c−D/2)/(D/2) | 除以 δ² | 覆盖失败率 |
|---|---|---|---|
| 0.5° | 1.41×10⁻⁴ | 1.86 | 0.62% |
| 1° | 5.76×10⁻⁴ | 1.89 | 0.94% |
| 2° | 2.25×10⁻³ | 1.85 | 2.12% |
| 4° | 8.39×10⁻³ | 1.72 | 4.58% |
| 8° | 2.95×10⁻² | 1.51 | 9.97% |

即 **R_c − D/2 = O(δ²·D)**，δ=1° 时约为 `2δ²·(D/2) ≈ 6×10⁻⁴·(D/2)`，绝对值远小于 20 m 的
清除判据。所以本问第二小问可以答「能覆盖」，但要写成「在 δ² 阶意义下」。

### 1.4 「等号成立当且仅当区域中心对称且直径端点为对径点」——**必要性错误**

充分性对，必要性错。反例（脚本 [2c] 段）：三角形 (0,0)、(10,0)、(5,1)，
最长边 10 m、第三个顶点处为钝角 ⇒ 最小外接圆就是以最长边为直径的圆
⇒ R_c = 5 = D/2，但该三角形**不是中心对称的**。

正确表述（Thales 判据）：

```
若 A,B ∈ S 且 |AB| = D，则「以 AB 为直径的圆覆盖 S」
   ⟺ 对任意 P ∈ S，∠APB ≥ 90°（即 (P−A)·(P−B) ≤ 0）
   ⟺ R(S) = D/2
```

中心对称 + 直径端点为对径点只是「等号成立」的一类充分条件，不是必要条件。

### 1.5 Jung 定理的引用——**方向相反**

平面（n=2）情形：

```
R(S) ≤ D · √( n/(2(n+1)) ) = D/√3 ≈ 0.5774 D      （等号：等边三角形）
```

因为 `D/√3 > D/2`，Jung 定理**不能**推出「以直径为直径的圆能覆盖」；
它的取等情形（等边三角形）恰好就是覆盖失败的例子。Jung 定理在本题只应出现在两个位置：

1. 说明「一般凸区域不行」——给出下界型反例（等边三角形）；
2. 当覆盖判定失败时，给一个**兜底**的保守覆盖半径 `D/√3`（算法上应有，但本题两站情形用不到）。

摘要里那句「并通过 Jung 定理」目前语义也不完整，必须重写（见 §4）。

## 2. 修正后的证明（可直接进论文）

### 定理 1（一般判据）

设 S ⊂ R² 有界，D = diam(S)，R_c = 最小覆盖圆半径，A、B ∈ S 为直径点（|AB| = D）。则

```
R_c ≥ D/2 ，且 R_c = D/2 ⟺ 以 AB 为直径的圆覆盖 S
```

**证明.** 任何覆盖圆都要同时装下 A、B，故 2R ≥ |AB| = D，即 R_c ≥ D/2。
若以 AB 为直径的圆（圆心 (A+B)/2、半径 D/2）覆盖 S，则 R_c ≤ D/2，结合 R_c ≥ D/2 得 R_c = D/2。
反之设 R_c = D/2、Ω 为最小覆盖圆：A、B ∈ Ω 且 |AB| = D = 2R_c，说明 A、B 是 Ω 的一对对径点，
于是 Ω 的圆心是 AB 的中点、半径是 D/2，即 Ω 恰是以 AB 为直径的圆。∎

**推论（反例）.** 等边三角形边长 d：D = d，R_c = d/√3 = 0.5774d > d/2，
以直径为直径的圆不覆盖它 ⇒ **一般凸多边形不能**。

### 定理 2（中心对称情形：问题 1 的肯定结论）

若区域 K 是中心对称凸集（对称中心 o），则 `R_c = D/2`，且**以任意直径对为直径的圆都是最小覆盖圆**。

**证明.** 设 ρ = max_{P∈K}|P−o|，取 P* 达到 ρ，则 −P*+2o ∈ K（中心对称），
故 D ≥ 2ρ；又 K 含于以 o 为心、ρ 为半径的圆中，故 D ≤ 2ρ，于是 D = 2ρ，R_c = ρ = D/2。
（唯一性：若存在半径 < ρ 的覆盖圆，它装不下距离为 2ρ 的对径点对。）∎

### 定理 3（条带模型下的完整结论）

在 ±1° 线性化模型 `A = {p : |p·n₁| ≤ w₁, |p·n₂| ≤ w₂}`（w_i = r_i tanδ，θ = ∠(n₁,n₂)）下：
A 是中心对称平行四边形，其最小外接圆半径

```
R_c = D/2 = tanδ · max( √(r₁²+r₂²−2r₁r₂cosθ), √(r₁²+r₂²+2r₁r₂cosθ) ) / sinθ
```

等于以区域直径为直径的圆的半径，故**能覆盖**。

**证明.** 由定理 2，只需证 A 中心对称：p ∈ A ⟺ n_i·p ∈ [−w_i, w_i] ⟺ −p ∈ A。
顶点为 ±p₊、±p₋（解 n_i·p = ±w_i 的四个组合），其中
`|p∓| = √(w₁²+w₂²∓2w₁w₂cosθ)/sinθ`，故对角线长 2|p₊|、2|p₋|，
D = 2max(|p₊|,|p₋|) 且最远顶点到中心距离 ρ = max(|p₊|,|p₋|) = D/2，
以中心为心、ρ 为半径的圆覆盖 A（凸包包含性）。∎

### 定理 4（精确楔交区域：把近似说清楚）

精确区域 A = W₁ ∩ W₂（四边由 4 条射线所在直线给出）**一般不是中心对称**，
`R_c = D/2` 只在 O(δ²) 精度下成立：δ = 1° 时数值最坏相对超出 ≈ 5.8×10⁻⁴
（脚本 [2]/[2b] 段，2 万随机样本 + 标度实验）。因此论文的口径应当二选一：

* **口径 A（推荐）**：把区域定义在条带线性化模型上，按定理 3 严格证明「能覆盖」，
  再用脚本 [1] 段表格说明它与精确楔交的偏差 ≤ 0.1%（可接受，且远小于 20 m）；
* **口径 B**：严格按精确楔交建模，结论写成「R_c = D/2 在 O(δ²) 意义下成立，
  δ=1° 时相对偏差 < 6×10⁻⁴；一般凸区域不成立（定理 1 推论）」。

### 定理 5（否定一般结论：本题模型内的显式反例，k = 3）

测站取等边布置（半径 1000 m，源在原点）：

```
S₁ = ( 1000.000,    0.000)
S₂ = ( −500.000,  866.025)
S₃ = ( −500.000, −866.025)
示向度 φ̂ = (181°, 300°, 61°)     ← 真值 180°/300°/60°，误差 (+1°, 0°, +1°)
```

三楔求交区域是一个三角形：

```
(0, 0), (−19.954280, 0), (−10.180280, −17.632762)
D = 20.360560 m ，D/2 = 10.180280 m
R_c = 11.639665 m        （比 D/2 大 14.34%）
顶点 (−19.954280, 0) 落在「以直径为直径的圆」外 7.101827 m
```

⇒ **该情形下直径圆不能覆盖定位区域**（而 7.1 m 的超出量与 20 m 的清除半径同量级，不可忽略）。
随机扫描（脚本 [4] 段，3–4 个测点、2 万样本）：覆盖失败率 **21.7%**，最坏相对超出 **14.6%**，
接近等边三角形（Jung 取等）的 15.47%。

因此若把题目里的「若干检测点」理解为 ≥3 个，问题 1 第二问的答案必须写「**不能**」；
只有两站交会（附录 2 图 2 的情形）才有「能覆盖」的结论。

## 3. 算法部分的附带问题（问题 1 第一小问）

1. 凸多边形直径由顶点对取得、旋转卡壳 O(n)（n 小时 O(n²) 暴力）——**正确**。
2. 最小外接圆枚举 2 点/3 点定圆——**正确**（凸区域时包含所有顶点即包含整个区域）。
3. 但代码里圆盘约束用**外接正多边形**近似（`DISC_N = 90`，`R = r/cos(π/90)`，
   区域被放大 0.06%）。这对「源在区域内」是保守的（安全），但论文若声称
   「算法给出精确定位区域/精确直径」，需要写明这是外逼近，或改用解析圆弧处理。
   同理，`R_c ≤ 20 m` 的清除判据用外逼近是**偏安全**的。
4. 若区域含圆弧边（目标圆域或 1500 m 接收圆盘起约束作用时），直径不一定在顶点取得，
   要考虑顶点—弧、弧—弧的极值；此时也不宜再称「多边形定位区域」。
