## 1. 记号与建模约定

题目给定两条硬事实（摘自 B 题附录 2 与附件 2）：

1. **误差是系统偏差**："在一段时间内，同一地点的电磁环境干扰是固定的，所以重复检测不会改变检测误差"，误差范围 `[−1°, 1°]`。
   因此测站 S 处读数 `φ̂` 与真实方位 `φ` 满足 `φ ∈ [φ̂−δ, φ̂+δ]`，其中 `δ = 1°`（三角计算用弧度，`tanδ = 0.017455`）。
2. **一次测量给出的是楔形，不是射线**：源必落在楔形
   `W(S, φ̂, δ) = { P : |∠(P−S, φ̂)| ≤ δ }` 内。

在 S₁ 处测得示向度后，掌握的信息集为

```
A₁ = W(S₁, φ̂₁, δ) ∩ { |S₁G| ≤ 1500 } ∩ { |OG| ≤ 1800 }
```

其中 `|S₁G| ≤ 1500` 来自"收到了信号"这一事实本身：能收到说明 `|S₁G| ≤ R_G`，而有效接收半径 `R_G ∈ [1000,1500]`（附件 2 §2.1）。

> **关键结构性观察**
> 一次测量给出了**方向**与**距离上界**，却完全没有给出**距离下界**——源的距离 `t` 可以小到 0，大到 1500 m。
> 这正是本题与文献中"已知目标距离 R"的经典结论不能直接对接的根源，也印证了谢鑫《无源定位优化布站分析研究》中对理论推导派的批评："并未考虑在实际应用中，在定位之前无法确切知道目标辐射源的位置"。

记两个测站为 S₁、S₂，源为 G：

```
r₁ = |GS₁|,  r₂ = |GS₂|,  L = |S₁S₂|,  θ = ∠S₁GS₂（交会角）
M  = 基线 S₁S₂ 的中点
R_c = 定位区域的最小外接圆半径
D   = 定位区域的直径（问题 1 所求量）
```

## 2. 引理 1：定位区域是中心对称平行四边形

**命题**：在两楔求交的线性化模型下，定位区域 `A = W₁ ∩ W₂` 是中心对称平行四边形。

**推导**：对 `W_i` 在 G 附近展开。点 `P = G + p` 位于 `W_i` 内，等价于向量 `P−S_i` 与 `G−S_i` 的夹角不超过 δ。记 `e_i` 为 `S_i → G` 的单位向量，则

```
|p × e_i| ≤ (r_i + p·e_i)·tanδ = r_i·tanδ + O(|p|·δ)
```

略去高阶项，`W_i` 在 G 附近退化为一条**以 G 为中心、法向 n_i ⊥ e_i、半宽 w_i = r_i·tanδ 的条带**：

```
A = { p : |p·n₁| ≤ w₁,  |p·n₂| ≤ w₂ }
```

两条带求交即平行四边形；约束关于 `p → −p` 对称，故**中心对称**。

**数值验证**（精确楔交 + 精确最小外接圆，非近似）。取 `r₁ = r₂ = 1000 m`：

| 交会角 θ | 区域直径 D（精确） | D 的解析式 | 最小外接圆半径 R_c | D/2 |
|---|---|---|---|---|
| 60° | 69.88 m | 69.82 m | 34.94 m | 34.94 |
| 75° | 57.38 m | 57.35 m | 28.69 m | 28.69 |
| **90°** | **49.39 m** | **49.37 m** | **24.69 m** | **24.69** |
| 105° | 57.33 m | 57.35 m | 28.66 m | 28.66 |
| 120° | 69.80 m | 69.82 m | 34.90 m | 34.90 |
| 150° | 134.84 m | 134.88 m | 67.42 m | 67.42 |

解析式与精确几何吻合到 10⁻³ 量级，且 `R_c = D/2` 严格成立。

## 3. 引理 2：对角线公式

平行四边形两条对角线长分别为（θ 为两法向之间的夹角，即交会角）

```
D∓ = 2·tanδ · √( r₁² + r₂² ∓ 2·r₁·r₂·cosθ ) / sinθ

D  = max( D₋ , D₊ )
```

**推导**：解线性方程组 `p·n₁ = w₁, p·n₂ = w₂`。令 `p = w₁·n₁ + s·m`（`m ⊥ n₁`），代入第二式：

```
p·n₂ = w₁·cosθ + s·(m·n₂) = w₂      ⇒   s = (±w₂ − w₁·cosθ)/sinθ
|p|² = w₁² + s² = ( w₁² + w₂² ∓ 2·w₁·w₂·cosθ ) / sin²θ
```

四种符号组合给出两个不同的长度（互为镜像对），故直径为 `2·max|p±|`，即上式。

### 两个等价的几何形式

把 `w_i = r_i·tanδ` 代回，并利用余弦定理 `r₁² + r₂² − 2r₁r₂cosθ = L²`：

**（1）与外接圆半径的联系**

```
D₋ = 2·tanδ · L / sinθ = 4·tanδ · R外 ,   其中 R外 = L / (2·sinθ) 是 △S₁GS₂ 的外接圆半径
```

**（2）与中线长度的联系**

由 `r₁² + r₂² + 2r₁r₂cosθ = |2G − S₁ − S₂|² = 4|G − M|²`（M 为基线中点）：

```
D₊ = 4·tanδ · |G − M| / sinθ
```

于是得到极简的闭式表达：

```
D = 4·tanδ · max( L / (2·sinθ) ,  |G − M| / sinθ )
```

**验算**：`r₁ = 1000, r₂ = 2000, θ = 90°` 时，`L = √5·10³ = 2236`，`R外 = L/2 = 1118`；`G = (0,0)`、`S₁ = (−1000,0)`、`S₂ = (0,2000)`、`M = (−500,1000)`，`|G−M| = 1118`。两项相等，`D = 4×0.017455×1118 = 78.06 m`，与精确值 78.1 m 一致。

## 4. 引理 3：最小外接圆半径恰为直径之半

**命题**：`R_c = D / 2`。

**证明**：由引理 1，区域是中心对称凸集。对中心对称凸集，最小外接圆圆心必在对称中心——否则沿偏离方向平移圆心可同时减小所有顶点的距离，与最小性矛盾。于是半径等于到最远顶点（即对角线端点）的距离，故 `R_c = max|p±| = D/2`。∎

**这个引理把问题 1 的量（区域直径）与清除判据（20 m）直接连起来了**：

> 取定位区域的对称中心作为清除点，当 `R_c ≤ 20 m` 时，源必落在这个圆盘内，**一次 `/clear` 必定命中**。

这条判据是问题 3、4 中"何时停止测量、可以直接去清除"的充要几何条件。

## 5. 定理 1：最优交会角恒为 90°

**命题**：对任意 `r₁, r₂ > 0`，`D(θ)` 在 `θ = 90°` 取唯一最小值，且 `D(θ) = D(180° − θ)`。

**证明**：记 `ρ = r₂/r₁ > 0`，`c = cosθ`。

### 情形一：θ ≤ 90°（c ≥ 0）

此时 `D₊ ≥ D₋`，故

```
D / (2·r₁·tanδ) = √(1 + ρ² + 2ρc) / √(1 − c²) =: f(c)

f²(c) = (1 + ρ² + 2ρc) / (1 − c²)

d(f²)/dc = [ 2ρ(1 − c²) + (1 + ρ² + 2ρc)·2c ] / (1 − c²)²
         = 2[ ρ + c + ρ²c + ρc² ] / (1 − c²)²  ≥ 0     （c ∈ [0,1] 时各项非负）
```

故 `f` 随 `c` 单调增；而 `c = cosθ` 随 θ 单调减，所以 `D` 在 `(0°, 90°]` 上单调减，最小值在 `θ = 90°`。

### 情形二：θ ≥ 90°（c ≤ 0）

此时 `D₋ ≥ D₊`，故

```
f²(c) = (1 + ρ² − 2ρc) / (1 − c²)

d(f²)/dc = [ −2ρ(1 − c²) + (1 + ρ² − 2ρc)·2c ] / (1 − c²)²
         = −2(ρ − c)(1 − ρc) / (1 − c²)²  ≤ 0        （c ≤ 0, ρ > 0 ⇒ ρ−c>0, 1−ρc>0）
```

故 `f²` 随 `c` 单调减，即 `f` 随 θ 在 `[90°, 180°)` 上单调增，最小值仍在 `θ = 90°`。

两种情形合并得全局唯一极小点 `θ* = 90°`；对称性 `D(θ) = D(180°−θ)` 由 `c → −c` 时两式互换立得。∎

### 推论（核心公式）

```
D_min  = 2·tanδ·√(r₁² + r₂²)
R_c,min = tanδ·√(r₁² + r₂²)
```

**数值校验**：`r₁ = r₂ = 1000 m` 时 `R_c,min = √2 × 1000 × tan1° = 24.685 m`，精确几何给出 24.693 m，偏差 0.03%。

**物理含义**：交会角取 90° 时，两条带的法向正交，两个方向的定位约束互不放大，误差最小。这也解释了为什么"基线"附近（θ→0° 或 180°）定位精度急剧变差（对应廖海军文中的"基线附近定位精度较低"）。

## 6. 定理 2：精度下界与 1146 m 判据

**命题**：`R_c ≥ r₁·tanδ`，等号仅在 `θ = 90°` 且 `r₂ → 0` 时达到。

**证明**：

- 情形一（θ ≤ 90°）：`R_c = tanδ·√(r₁² + r₂² + 2r₁r₂cosθ) / sinθ ≥ r₁·tanδ / sinθ ≥ r₁·tanδ`。
- 情形二（θ ≥ 90°）：`R_c = tanδ·L / sinθ ≥ tanδ·r₁`（因 `cosθ ≤ 0 ⇒ L² = r₁² + r₂² − 2r₁r₂cosθ ≥ r₁²`，且 `sinθ ≤ 1`）。∎

### 这是一个硬性的不可能性结论

> 无论第二个测点放在哪里，定位误差都不会小于 `0.017455·r₁`。
> 因此若要在 20 m 内保证一次清除，**第一个测点距源必须满足**
>
> ```
> r₁ ≤ 20 / tan1° = 1145.8 m
> ```

由于有效接收半径可达 1500 m，**第一次检测完全可能发生在 `r₁ > 1146 m` 处，此时任何第二测点都无法保证一次清除**。

这从根本上解释了机器狗为什么必须"测—逼近—再测"迭代，而不能指望"两次交会就收工"。

若进一步取最优的等距配置（`r₁ = r₂ = t, θ = 90°`）：

```
R_c = √2·t·tanδ ≤ 20   ⇔   t ≤ 810.2 m
```

## 7. 定理 3：理想第二点的轨迹

若源的**距离**已知为 `t₀`，则由 `θ = 90°` 且 `r₂ = r₁ = t₀` 最优，解得第二点位置。

设局部极坐标以 S₁ 为极点、测得示向度方向为极轴、源位于 `(t₀, 0)`：

```
q*(t₀) = ( √2·t₀ ,  ±45° )

R_c(q*) = √2·t₀·tanδ = 0.024686·t₀
```

**几何含义**：以 G 为原点，把 `S₁ → G` 方向旋转 90° 并取等距点，即 `G + (0, ±t₀)`；从 S₁ 看去恰好是偏离示向度 `±45°`、距离 `√2·t₀` 的点。

| 假定源距 t₀ | 理想第二点距 S₁ 的距离 d = √2·t₀ | 可达 R_c | 能否一次清除 |
|---|---|---|---|
| 300 m | 424 m | 7.4 m | ✅ |
| 600 m | 849 m | 14.8 m | ✅ |
| **810 m** | **1146 m** | **20.0 m** | 临界 |
| 1000 m | 1414 m | 24.7 m | ❌ |
| 1500 m | 2121 m | 37.0 m | ❌ |

**但距离不可观测**，`q*(t₀)` 随 `t₀` 变化，所以真正能给出的只能是**区域**而不是点——这正是题目要求"候选区域"的原因。

## 8. 距离不可观测性与极小极大解

由于 `t` 未知，采用最坏情况（min-max）准则：

```
q* = argmin_q  max_{ t ∈ (0,1500] }  R_c(q; t)
```

数值求解（精确楔交 + 精确最小外接圆；t 取 100–1500 m 共 10 个代表值；`(d, ψ)` 网格搜索）：

```
d* = 1500 m,   ψ* = ±40°,   max_t R_c = 38.8 m
```

该配置的逐距离表现：

| 源距 t | 第二站距源 r₂ | 实际交会角 θ | 定位误差 R_c |
|---|---|---|---|
| 100 m | 1425 m | 137.4° | 38.68 m |
| 300 m | 1285 m | 131.4° | 34.88 m |
| 600 m | 1110 m | 119.7° | 30.12 m |

## 9. 第二个检测点的候选区域（问题 2 的最终答案）

以 S₁ 为极点、测得示向度方向为极轴，记第二点为 `(d, ψ)`（ψ 可取正负，关于示向度方向上下对称）。

### （a）方向条件

交会角随源距 `t` 单调递减，从 `t → 0` 时的 `180° − ψ` 降到 `t → ∞` 时的 `0°`，转折点（θ = 90°）在 `t = d·cosψ`。故"全程都落在可接受交会带 `[75°, 125°]`"的充要条件为

```
ψ ∈ [55°, 105°)

d ≥ 1500·tan75° / ( sinψ + tan75°·cosψ ) = 5598 / ( sinψ + 3.732·cosψ )
```

（此结论与修建娟文中"交会角范围 75°–125°"的口径一致。）

### （b）误差水平集（推荐使用的候选区域）

直接以"最坏情况 `R_c` 不超过给定值"定义候选区域，数值结果：

| 最坏 R_c 上界 | 允许的 ψ | 允许的 d |
|---|---|---|
| **≤ 40 m** | ±[35°, 45°] | 1375 – 1675 m |
| **≤ 45 m** | ±[30°, 55°] | 1225 – 2150 m |
| ≤ 50 m | ±[25°, 60°] | 1150 – 2525 m |
| ≤ 60 m | ±[20°, 70°] | 1025 – 3150 m |

### （c）最终推荐策略（三档，按已知信息多少选用）

| 情形 | 第二点取法 | 可达 R_c |
|---|---|---|
| **有距离估计 t̂** | `ψ = ±45°, d = √2·t̂`（定理 3 的理想点） | `0.0247·t̂` |
| **距离完全未知**（问题 2 标准情形） | `ψ = ±40°, d ≈ 1500 m`；直角坐标下 `S₂ ≈ (1150, ±964)` | 最坏 38.8 m |
| **允许先逼近再测**（问题 3/4 实际做法） | 先沿示向度逼近到 `t ≤ 810 m`，再取 `ψ = ±45°, d = √2·t` | ≤ 20 m，一次清除必中 |

## 10. 与文献「最优交会角 110°」的对照

修建娟等（2005，《宇航学报》）在**随机误差 + 圆概率误差（CEP）**准则下给出

```
r₀.₅ = 0.8·L·√( sin²θ₂·σ₁² + sin²θ₁·σ₂² ) / sin²β

min w = ( sin²θ₁ + sin²θ₂ ) / sin⁴β
```

代入等腰几何 `θ₁ = 90° − β/2, θ₂ = 90° + β/2`，最小化 `w = 2cos²(β/2)/sin⁴β` 得

```
β* = 109.5° ≈ 110°,   此时 L = 2R·tan55° = 2.8563·R
```

（按同口径复算：`L/R = 2·tan(β/2) = 2.856`，与文献 2.8563 完全一致，说明建模口径对得上。）

### 对照表

| | 文献（修建娟 2005） | 本题推导 |
|---|---|---|
| 误差模型 | 零均值高斯随机误差 | **每地点固定的系统偏差** |
| 评价准则 | 圆概率误差 CEP（期望） | **最坏情况定位区域（保证）** |
| 最优几何 | 等腰，θ\* = 109.5° | **等腰，θ\* = 90°** |
| 位置关系 | L = 2.8563·R | `d = √2·t, ψ = ±45°` |
| 对应误差量 | r₀.₅ | `R_c = tanδ·√(r₁²+r₂²)` |

### 差异原因

CEP 公式中，分子 `sin²θ₁ + sin²θ₂` 随交会角增大而减小，分母 `sin⁴β` 在 90° 取极大，两种趋势的折中把最优点从 90° 推到 110°；而最坏区域准则下两者同向，区域尺寸 `∝ 1/min(sin(θ/2), cos(θ/2))`，关于 90° 严格对称且唯一极小。

**两者都推出"等腰 / 中垂线"的一致结论，分歧只在交会角**——这正说明本题必须针对自己的误差模型重推，不能照搬文献。

## 11. 对问题 3、4 的接口

1. **第二点选址**：`ψ = ±40°, d ≈ 1500 m`；或按第 9 节候选区域取。
2. **逼近判据**：`R_c ≤ 20 m` 是清除的充要几何判据。由定理 2，只有 `r₁ ≤ 1146 m` 时才可能达到，等距时 `t ≤ 810 m`。所以算法应写成"**沿示向度逼近到 800 m 内再交会**"，而不是"两次测量后直接去清除"。
3. **多站选优**：一个目标被 3 个以上测站测到时，对每对组合计算
   `R_c = tanδ·√(r₁²+r₂²) / min(sin(θ/2), cos(θ/2))`，取最小的那对执行清除。这同时实现了廖海军"最小方差选优"与王成"残差置信度"两种思路。
4. **问题 4 的额外退化处理**：定向源在盲区内返回 `no_signal`，某对测站可能无法交会；此时回退到"单站示向度 + 沿方位逼近 + 20 m 内 `/clear`"（因为 `/clear` 不受定向朝向限制，见附件 2 §2.4）。
